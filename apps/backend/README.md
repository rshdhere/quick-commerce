# Fastify backend

Install dependencies with `bun install` from the repository root. In this directory, run `bun run dev` for watch mode or `bun start` to run the server.

The health endpoint is available at `http://127.0.0.1:3001/health`. Set `HOST` and `PORT` to change the listener. The Next.js frontend runs from `apps/frontend` on port 3000.
